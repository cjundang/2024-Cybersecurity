## 2. IDS/IPS Fundamentals

### Definition

| Type | Description |
|------|--------------|
| **IDS** | Intrusion Detection System — passive detection & alerting |
| **IPS** | Intrusion Prevention System — inline blocking & mitigation |

**Function:**  
Monitor network traffic → Apply rules/patterns → Detect or block malicious activity.

---

### IDS vs IPS Comparison

| Feature | IDS | IPS |
|----------|-----|-----|
| Mode | Passive (Tap/SPAN) | Inline (Firewall gateway) |
| Action | Alert only | Drop/block packets |
| Risk | Zero network disruption | May impact latency |
| Example | Suricata IDS mode | Suricata + NFQUEUE (inline) |

---

## Detection Techniques

| Technique | Concept | Strength | Limitation |
|------------|----------|-----------|-------------|
| **Signature-based** | Match known patterns | Accurate for known threats | Misses zero-days |
| **Anomaly-based** | Detect unusual behavior | Detects new attacks | Higher false positives |
| **Hybrid** | Combine both | Balanced | Complex tuning |

---

## 3. Core IDS/IPS Components

| Component | Description |
|------------|--------------|
| **Packet Capture** | Raw network data (libpcap, AF_PACKET) |
| **Decoder** | Protocol parsing (Ethernet, IP, TCP, DNS, HTTP) |
| **Detection Engine** | Rule and pattern matching |
| **Logger** | Output alerts (EVE JSON, Syslog) |
| **Console / Dashboard** | Management and visualization |

---

## Snort vs Suricata

| Feature | Snort | Suricata |
|----------|--------|----------|
| Developer | Cisco | OISF |
| Multithreading | No | Yes |
| Rule Format | Snort rules | Compatible (Snort-style) |
| Output | Text | JSON (EVE) |
| Performance | Single core | Multi-core optimized |
| Use Case | Legacy networks | Modern high-speed networks |

## 4. Suricata Architecture

```
       ┌──────────────┐
       │ Packet Input │
       └──────┬───────┘
              │
      [Protocol Decoding]
              │
      [Detection Engine]
     ┌────────┼─────────┐
     │ Alerts │ Logs │ Stats │
     └────────┴─────────┘
             ↓
       JSON (EVE Output)
```

## Suricata Rule Example

```

alert tcp any any -> any 80 (msg:"HTTP Shell Upload"; content:"cmd="; nocase; sid:10001;)

````

**Fields:**
- `alert` = action  
- `tcp any any -> any 80` = match criteria  
- `(msg:"HTTP Shell Upload"; content:"cmd="; sid:10001;)` = options

✅ **Snort-compatible syntax**

---

## Example Rule — ICMP Flood

```bash
alert icmp any any -> 192.168.1.10 any (msg:"ICMP Flood Detected"; itype:8; threshold:type both, track by_dst, count 50, seconds 1; sid:300001;)
```

Detects ICMP ping floods (>50 packets/sec).

## 5. Alert Handling

**EVE JSON Format**

```json
{
  "timestamp": "2025-11-06T09:44:02.100Z",
  "src_ip": "192.168.1.20",
  "dest_ip": "10.0.0.8",
  "proto": "TCP",
  "alert": {
    "signature_id": 10001,
    "signature": "HTTP Shell Upload",
    "severity": 3
  }
}
```

## 5. Alert Handling

**Alert Response Steps**

1. **Detect** → rule triggered
2. **Validate** → check context
3. **Respond** → block, isolate, or notify
4. **Tune** → modify rules to reduce false positives

## 8. Machine Learning Integration

### Workflow

1. Extract Suricata logs (EVE JSON).
2. Convert to numerical features.
3. Train ML model (e.g., Isolation Forest).
4. Classify alerts as **normal/anomalous**.
5. Stream results to dashboard in real-time.

---

### Example ML Integration Code

```python
import json, pandas as pd
from sklearn.ensemble import IsolationForest

with open("eve.json") as f:
    alerts = [json.loads(l) for l in f if '"alert"' in l]

df = pd.DataFrame([{
    "sig_id": a["alert"]["signature_id"],
    "severity": a["alert"]["severity"]
} for a in alerts])

model = IsolationForest(contamination=0.1)
df["score"] = model.fit_predict(df)
df["label"] = df["score"].map({1:"normal", -1:"anomaly"})
print(df.head())
```

✅ Model isolates rare / suspicious alerts.

## 9. Real-time Visualization with WebSocket

**Why WebSocket?**

* Persistent two-way connection.
* Push new IDS alerts immediately.
* Ideal for SOC dashboards and live incident response.

---

### FastAPI Backend with WebSocket

```python
from fastapi import FastAPI, WebSocket
import json, asyncio

app = FastAPI()

@app.websocket("/ws/alerts")
async def ws_alerts(ws: WebSocket):
    await ws.accept()
    while True:
        with open("/var/log/suricata/eve.json") as f:
            data = [json.loads(line) for line in f.readlines()[-5:]]
        await ws.send_text(json.dumps(data))
        await asyncio.sleep(2)
```

✅ Sends last 5 alerts every 2 seconds.

---

### ReactJS Frontend Example

```jsx
import React, { useEffect, useState } from "react";

export default function LiveAlerts() {
  const [alerts, setAlerts] = useState([]);
  useEffect(() => {
    const ws = new WebSocket("ws://localhost:8000/ws/alerts");
    ws.onmessage = e => setAlerts(JSON.parse(e.data));
    return () => ws.close();
  }, []);
  return (
    <div className="p-6">
      <h2 className="text-2xl font-bold mb-2">Live Suricata Alerts</h2>
      <ul>
        {alerts.map((a, i) => (
          <li key={i} className="border-b py-1">
            [{a.timestamp}] {a.alert.signature} ({a.src_ip} → {a.dest_ip})
          </li>
        ))}
      </ul>
    </div>
  );
}
```

✅ Realtime visualization of IDS activity in browser.
